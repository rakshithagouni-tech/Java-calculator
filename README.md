# Java Swing GUI Calculator

A lightweight, responsive, and standalone desktop calculator application built using Java's foundational standard libraries. This project demonstrates core Object-Oriented Programming (OOP) concepts, robust event-driven programming, implementation of layout structures, and math logic handling within a visual interface.

## Features
*   **Core Arithmetic**: Seamlessly handles Addition (`+`), Subtraction (`-`), Multiplication (`*`), and Division (`/`).
*   **Dynamic UI Layout**: Built with a clean `Grid layout` housing custom-styled number and function buttons.
*   **Smart Math Processing**: Includes decimal point integration, multi-step calculation chaining, and backspace text deletion.
*   **Error Prevention Handling**: Gracefully intercepts runtime mathematical faults like division by zero, protecting the software from unexpected crashes.

## Technologies Used
*   **Language**: Java (JDK 8 or higher)
*   **GUI Framework**: Java Swing (`javax.swing.*`)
*   **Layout Management**: Abstract Window Toolkit (`java.awt.*`)
*   **Event Handling**: `Action listener` configuration

## How to Run This Project
1. Clone or download the `Calculator.java` file to your computer.
2. Open your command terminal in that directory.
3. Compile the file using the Java compiler:
   ```bash
   javac Calculator.java
   ```
4. Run the executable application:
   ```bash
   java Calculator
   ```
